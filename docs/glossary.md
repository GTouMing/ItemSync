# 词汇表 / Ubiquitous Language

本文件是本项目唯一的术语来源。代码、UI 文案、ADR、测试命名都必须使用这里的词，不得混用同义词。

## 身份、信任与组织

| 术语 (中文 / English)                | 定义                                                                                                                     | 明确不是什么                                          |
|--------------------------------------|--------------------------------------------------------------------------------------------------------------------------|-------------------------------------------------------|
| 设备 / Device                        | 一台运行本软件的物理机器（Windows PC 或 Android 手机）。由设备密钥对与 `deviceId` 标识。                                 | 不是用户，不是进程                                    |
| 节点 / Node                          | 一次运行中的实例（桌面托盘进程 / Android 前台服务宿主）。                                                                | 不是设备本身：重装后是同设备、新节点                  |
| 本机账号 / Local Account             | 只属于单台设备的用户名 + 口令，口令以 Argon2id 哈希存储，用于解锁 UI 与破坏性操作校验。                                  | 不是可漫游的全局账号                                  |
| 节点解锁密钥 / Node Unlock Key (NUK) | 首次登录后生成、由平台密钥库封装的密钥，使节点在开机自启时无需人工输入口令即可运行。                                     | 不是账号口令                                          |
| 身份文件 / Identity Keystore         | 本机保存 TLS 私钥与自签证书的 PKCS12 文件（当前 CLI/桌面实现为 `identity.p12`；生产环境应迁到平台密钥库，见 ADR-0013）。 | 不是账号数据库，不是网络会话密钥                      |
| 密钥库口令 / Keystore Password       | 加密并解锁本机身份文件（`identity.p12`）的口令；首次运行时由用户设置，仅在本机使用。                                     | 不是本机账号口令；不是组 ID；不是 NUK；不在网络上传输 |
| 配对 / Pairing                       | 两个节点建立**传输层**信任的一次性流程：交换自签名证书并固定指纹。                                                       | 不是登录；配对不传口令，也不代表同意共享              |
| 信任邻居 / Trusted Peer              | 证书指纹已被固定的对端节点。                                                                                             | 不是“已同意共享”                                      |
| 撤销 / Revoke                        | 从信任列表移除某邻居证书，此后无法建立连接。                                                                             | 不是删除数据                                          |
| 组 ID / Group ID                     | 8 位随机串（字符集 `[0-9a-z]`，约 41 bit 熵），创建同步组时生成，是**入组凭据**。                                        | 不是加密密钥；不是组内共享授权                        |
| 同步组 / Sync Group                  | 一个逻辑上的成员集合，包含组 ID、成员表与一组同步根；无中心服务。                                                        | 不是进程，不是服务器                                  |
| 组成员 / Group Member                | 持有组 ID 并已出现在成员表中的节点。                                                                                     | 不代表已同意共享                                      |
| 共享同意 / Sharing Consent           | 成员两两之间的开关；**双方都同意**才建立同步。                                                                           | 不是配对，不是入组                                    |
| 黑名单 / Blocklist                   | 某成员单方面把另一设备移出自己的视野，不再收发其通知与数据。                                                             | 不是撤销证书                                          |
| 组 ID 轮换 / Group ID Rotation       | 更换组 ID，旧 ID 立即失效，所有成员需重新输入。                                                                          | 不是重建组                                            |

## 同步配置

| 术语 (中文 / English)     | 定义                                                                                            | 明确不是什么                 |
|---------------------------|-------------------------------------------------------------------------------------------------|------------------------------|
| 同步根 / Sync Root        | 参与同步的本地目录，归属某个同步组。Windows 为文件系统路径；Android 为真实路径（见 ADR-0010）。 | 不是单个文件                 |
| 数据目录 / Data Directory | 存放本机数据库、Blob、身份文件与配置的目录，由 `--data` 指定。                                  | 不是同步根；不应位于同步根内 |
| 同步项 / Item             | 同步根内一个逻辑路径条目（文件或目录）。                                                        | 不是 Blob                    |
| .isignore                 | 同步根**根目录**下的忽略规则文件，gitignore 语法，仅在本同步根生效，本身参与同步。              | 不是多级继承的 gitignore     |
| 排除规则 / Exclude Rule   | 来自 `.isignore` 的匹配模式；匹配对象是逻辑名。                                                 | 不是“隐藏文件”开关           |
| 方向模式 / Direction Mode | 同步组内的语义：`BIDIRECTIONAL`（默认）、`MIRROR`、`RECEIVE_ONLY`。                             | 不是设备角色                 |
| 同步根嵌套 / Nested Root  | 一个同步根位于另一个同步根之内；允许但强警告（ADR-0022）。                                      | 不是自动排除                 |

## 内容与版本

| 术语 (中文 / English)     | 定义                                                                                    | 明确不是什么             |
|---------------------------|-----------------------------------------------------------------------------------------|--------------------------|
| Blob                      | 不可变的文件内容对象，文件名为内容 SHA-256，存放于 `blobs/aa/<hash>`，天然去重。        | 不是文件；不带路径与时间 |
| 清单 / Manifest           | 一次扫描产生的 `逻辑路径 → (内容哈希, 大小, mtime, 权限位)` 映射，按批流式处理。        | 不是版本历史             |
| 文件版本 / FileVersion    | 某同步项在某节点上的一次内容版本：Blob 引用 + 元数据 + 来源节点 + 产生它的 Sync Run。   | 不是整盘快照             |
| 版本索引 / Version Index  | 节点本地记录的全部 FileVersion，用于历史浏览、回滚与 GC。**不跨节点自动复制**。         | 不是组共享历史           |
| 版本向量 / Version Vector | 每个同步项上的 `{nodeId → counter}` 映射，用于判断版本之间是否存在因果关系。            | 不是计数器，不是墙钟时间 |
| 逻辑时间 / Logical Time   | 持久化的 Lamport 计数器，用于 `NOTIFY` 排序与并发仲裁；重启后不得回退。                 | 不是系统时钟             |
| 墓碑 / Tombstone          | 记录“该路径在某版本被删除”并携带版本向量的标记，用于传播删除。                          | 不是立即物理删除         |
| 冲突 / Conflict           | 同一逻辑路径的两个版本向量**不可比**（双方都发生了变更，含删除 vs 修改）。              | 不是同步失败             |
| 冲突副本 / Conflict Copy  | 冲突时为保留双方内容生成的额外文件，命名 `原名 (conflict <deviceId> <timestamp>).ext`。 | 不是可自动清理的垃圾     |
| 回滚 / Rollback           | 把某个同步项的本地内容恢复为指定 FileVersion，并作为一次新的本地变更参与后续同步。      | 不是整库还原             |

## 触发与运行

| 术语 (中文 / English)          | 定义                                                                                           | 明确不是什么               |
|--------------------------------|------------------------------------------------------------------------------------------------|----------------------------|
| 触发器 / Trigger               | 启动一次同步的条件：闹钟触发器、条件触发器、手动触发。                                         | 不是同步组本身             |
| 闹钟触发器 / Alarm Trigger     | **定时同步**：按“哪周哪几天的哪时哪分”的日历规则触发，带时区。                                 | 不是固定间隔轮询           |
| 条件触发器 / Condition Trigger | **计划同步**：由条件源触发，可组合：目录变动、目标应用启动、目标应用退出（后两者仅 Windows）。 | 不是 cron                  |
| 防抖窗口 / Debounce            | 条件命中后等待静默期（默认 30s），期间新事件重置计时，避免一次大拷贝触发多次同步。             | 不是限流                   |
| 立即同步 / Manual Sync         | 用户手动触发、绕过防抖的同步运行。                                                             | 不是“强制覆盖”             |
| 同步运行 / Sync Run            | 一次触发产生的同步会话，作用域是“某同步根 × 某同步组”。                                        | 不是同步组，不是节点级任务 |
| 扫描 / Scan                    | 遍历同步根生成本地 Manifest；扫描期间的变动由 watcher 记录并在应用后复扫。                     | 不是校验                   |
| 变更通知 / NOTIFY              | 变更方向组内在线且已同意成员发送的帧，携带 `runId`、变更摘要与向量快照。                       | 不是传输本身；不持久化     |
| 只收模式 / RECEIVE_ONLY        | 收到 NOTIFY 后，对**该组**临时生效的方向模式：只从发起方拉取。                                 | 不是永久配置               |
| 反推 / Reverse Push            | 只收模式结束后，若本地向量领先于源，立即把未推送变更推回源。                                   | 不是第二轮同步             |
| 传输会话 / Transfer Session    | 节点间一条连接内的分块、可续传的内容传输。                                                     | 不是持久连接               |
| 应用 / Apply                   | 把对端版本写入本地文件系统，含原子替换、PathCodec 编码与冲突副本生成。                         | 不是“提交”                 |
| 运行历史 / Run History         | 每次 Sync Run 的状态、统计与错误码记录，保留最近 200 次。                                      | 不是日志文件               |
| 诊断包 / Diagnostics Bundle    | 一键导出的 zip：脱敏配置、日志、清单摘要、冲突列表、平台能力信息。                             | 不含口令、私钥、文件内容   |

## 平台与生命周期

| 术语 (中文 / English)          | 定义                                                                             | 明确不是什么   |
|--------------------------------|----------------------------------------------------------------------------------|----------------|
| 自启动 / Autostart             | 设备开机后自动拉起节点。Windows 走 `HKCU\...\Run`；Android 走 `BOOT_COMPLETED`。 | 不是“默认启动” |
| 默认启动 / Start by Default    | 安装或首次运行后默认处于运行状态（托盘 / 前台服务）。                            | 不是开机自启   |
| 前台服务 / Foreground Service  | Android 上带常驻通知的长生命周期服务，类型 `dataSync`，是唯一合规的保活手段。    | 不是后台线程   |
| 保活 / Keep-alive              | 尽力让节点在后台存活；失败后靠闹钟 / WorkManager 恢复。**不承诺 100%**。         | 不是永恒后台   |
| 托盘 / Tray                    | Windows 端的常驻 UI 入口（最小化后不占任务栏）。                                 | 不是主窗口     |
| 平台能力 / Platform Capability | 某平台是否支持某功能（如监听第三方应用启停仅 Windows）。UI 必须按能力矩阵渲染。  | 不是运行时探测 |
| 错误码 / Error Code            | 共享层统一定义的稳定枚举（如 `BLOB_HASH_MISMATCH`），日志、UI 与文档共用。       | 不是异常堆栈   |
