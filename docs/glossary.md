# 词汇表 / Ubiquitous Language

本文件是本项目唯一的术语来源。代码、UI 文案、ADR、测试命名都必须使用这里的词，不得混用同义词。

## 身份、信任与组织

| 术语 (中文 / English)                | 定义                                                                                            | 明确不是什么                                |
|--------------------------------------|-------------------------------------------------------------------------------------------------|---------------------------------------------|
| 设备 / Device                        | 一台运行本软件的物理机器（Windows PC 或 Android 手机）。由设备密钥对与 `deviceId` 标识。        | 不是用户，不是进程                          |
| 节点 / Node                          | 一次运行中的实例（桌面托盘进程 / Android 前台服务宿主）。                                       | 不是设备本身：重装后是同设备、新节点        |
| 本机密码 / Local Password            | 首次启动设置的单机口令，Argon2id 哈希存储；只解锁 GUI 的查看与操作，后台同步不需要它。          | 不是用户名/账号；不是 NUK；不是数据加密密钥 |
| 节点解锁密钥 / Node Unlock Key (NUK) | 首次启动随机生成、由平台密钥库（DPAPI / Android Keystore）封装的密钥，用于静默解锁本机身份。    | 不是本机密码；不是组密钥                    |
| 本机身份 / Node Identity             | 本机的 TLS 密钥对与自签证书；由 NUK 解锁，用于 mTLS。                                           | 不是账号；不是同步数据                      |
| 证书指纹 / Certificate Fingerprint   | 节点自签证书 DER 的 SHA-256，用于配对确认与证书固定。                                           | 不是组 ID；不是口令                         |
| 配对 / Pairing                       | 同组两节点开启成对信任并固定当前证书指纹的一次性流程；首次信任是 TOFU。                         | 不是登录；不是信任开关本身；不传口令；不使用短码 |
| 首次信任 / TOFU                      | 首次开启信任时直接固定当前发现/确认到的证书指纹；无法抵御首次中间人。                           | 不是配对确认；不是组级信任；不验证首次证书归属 |
| 配对状态 / Pairing Status            | 某个组内未建立同步连接时，通过配对端点查询到的“对端是否信任本机”的只读结果：`TRUSTED`、`UNTRUSTED` 或 `UNKNOWN`；已建立同步 TLS 连接时直接视为 `TRUSTED`，不查询。 | 不是信任开关本身；不代表可同步；不修改远端状态；不是跨组状态 |
| 已连接 / Connected                   | 某个组内本机与对端之间存在已建立的同步 TLS 连接（出站或入站）；握手要求双方在该组固定证书。 | 不是跨组状态；不是持久状态；撤销或心跳失败会关闭连接；不代表可同步 |
| 配对状态查询失败 / Pairing Status Query Failure | 某个组内未连接时读取远端信任状态的失败结果：未提供配对端点、查询超时、身份校验失败、连接失败。 | 不是“对端不信任你”；不改变信任状态；不是连接活性结论 |
| 配对端点 / Pairing Endpoint          | 与同步端口分离的 TLS 元数据端点，按请求中的组 ID 返回该组身份与信任状态；一个节点一个端点。 | 不是同步端口；不传文件数据；不能用于固定证书 |
| 信任邻居 / Trusted Peer              | 同一组内证书指纹已固定且与本机互相信任的节点。 | 不是“同组”；不是“已开启信任”；不是跨组信任 |
| 撤销 / Revoke                        | 关闭某个组对某节点的信任并移除该组的固定证书；其他组不受影响；再次同步需重新配对。 | 不是删除数据；不是改组 ID；不是跨组撤销 |
| 组 ID / Group ID                     | 8 位 `[0-9a-z]` 串，创建时随机生成或加入时输入；同一局域网内同 ID 即同组，是发现命名空间；同时唯一标识该组的本地同步根，创建后不可改。 | 不是入组凭据；不是秘密；不是加密/认证密钥；不是可原地修改的配置 |
| 同步组 / Sync Group                  | 本机持久化的同步配置单元：本地组名、不可变组 ID、恰好一个同步根、若干同步规则、组内设备列表；同组 ID 的设备可互相发现；每台设备最多 5 个活跃组。 | 不是服务器；不是服务端成员表/邀请/审批；不是组级总信任开关 |
| 组内设备列表 / Group Device List     | 某个组持久化的已知设备集合，按 `(组 ID, 设备 ID)` 区分；包含设备名、设备 ID、最近在线、证书指纹与信任状态。首次发现自动加入；同一设备在多个组各有独立记录。 | 不是当前在线设备列表；不是已信任设备；不是跨组共享列表；不是服务端成员表 |
| 信任开关 / Sync Trust                | 按 `(组 ID, 对端证书指纹)` 保存的成对开关；同一设备在不同组分别保存。双方都开才同步，任一方关闭立即停止。 | 不是组级总开关；不是配对；不是全局设备信任 |
| 在线状态 / Presence                  | 某个组内可见的设备名、设备 ID、在线/离线、最近在线时间与本地/远端信任状态；同一设备在多个组分别计算。 | 不含同步根、文件名或文件内容；不代表可同步；不是跨组全局状态 |
| 改组 ID / Group ID Change            | 组 ID 创建后不可原地修改；换 ID 的方式是删除旧组（保留本地文件）后新建组。旧组的信任、规则、游标和版本历史随删除清理。 | 不是原地修改；不是轮换凭据；不是删除本地文件 |
| 停用组 / Disabled Group              | 停止该组的发现、同步和连接，保留组配置、信任与本地根；重新启用即恢复。 | 不是删除组；不是撤销信任；不是离线状态 |

## 同步配置

| 术语 (中文 / English)     | 定义                                                                                                    | 明确不是什么                 |
|---------------------------|---------------------------------------------------------------------------------------------------------|------------------------------|
| 同步根 / Sync Root        | 组内的本地物理目录及忽略快照；一个组恰好一个同步根，作为组的一部分，不再有独立根 ID。Windows 为文件系统路径；Android 为真实路径（见 ADR-0010）。 | 不是独立可寻址实体；不是单个文件；不是可跨组共享的目录 |
| 数据目录 / Data Directory | 存放本机数据库、Blob 与配置的目录，由 `--data` 指定。                                                   | 不是同步根；不应位于同步根内 |
| 同步项 / Item             | 同步根内一个逻辑路径条目（文件或目录）。                                                                | 不是 Blob                    |
| .isignore                 | 同步根**根目录**下的忽略规则文件，gitignore 语法，仅在本同步根生效，本身参与同步。                      | 不是多级继承的 gitignore     |
| 排除规则 / Exclude Rule   | 来自 `.isignore` 的匹配模式；匹配对象是逻辑名。                                                         | 不是“隐藏文件”开关           |
| 方向模式 / Direction Mode | 同步组内的语义：`BIDIRECTIONAL`（默认）、`MIRROR`、`RECEIVE_ONLY`。                                     | 不是设备角色                 |
| 跨组根重叠 / Cross-group Root Overlap | 两个组指向同一物理目录，或一个组的根位于另一个组的根之内；禁止，因为两个同步引擎会写同一棵树。 | 不是允许的嵌套根（ADR-0022 被替代）；不是同一组内的多根（一组一根） |

## 内容与版本

| 术语 (中文 / English)     | 定义                                                                                    | 明确不是什么             |
|---------------------------|-----------------------------------------------------------------------------------------|--------------------------|
| Blob                      | 不可变的文件内容对象，文件名为内容 SHA-256，存放于 `blobs/aa/<hash>`，天然去重。        | 不是文件；不带路径与时间 |
| 清单 / Manifest           | 一次扫描产生的 `逻辑路径 → (内容哈希, 大小, mtime, 权限位)` 映射，按批流式处理。        | 不是版本历史             |
| 文件版本 / FileVersion    | 某同步项在某节点上的一次内容版本：Blob 引用 + 元数据 + 来源节点 + 产生它的 Sync Run。   | 不是整盘快照             |
| 版本索引 / Version Index  | 节点本地记录的全部 FileVersion，用于历史浏览、回滚与 GC。**不跨节点自动复制**。         | 不是组共享历史           |
| 版本向量 / Version Vector | 每个同步项上的 `{nodeId → counter}` 映射，用于判断版本之间是否存在因果关系。            | 不是计数器，不是墙钟时间 |
| 逻辑时间 / Logical Time   | 持久化的 Lamport 计数器，用于 `NOTIFY` 排序与并发仲裁；重启后不得回退。                 | 不是系统时钟             |
| 墓碑 / Tombstone          | 记录“该路径在某版本被删除”并携带版本向量的标记，用于传播删除。                          | 不是立即物理删除         |
| 冲突 / Conflict           | 同一逻辑路径的两个版本向量**不可比**（双方都发生了变更，含删除 vs 修改）。              | 不是同步失败             |
| 冲突副本 / Conflict Copy  | 冲突时为保留双方内容生成的额外文件，命名 `原名 (conflict <deviceId> <timestamp>).ext`。 | 不是可自动清理的垃圾     |
| 回滚 / Rollback           | 把某个同步项的本地内容恢复为指定 FileVersion，并作为一次新的本地变更参与后续同步。      | 不是整库还原             |

## 触发与运行

| 术语 (中文 / English)          | 定义                                                                                           | 明确不是什么               |
|--------------------------------|------------------------------------------------------------------------------------------------|----------------------------|
| 同步规则 / Sync Rule           | 组内的一条调度规则，触发该组的同步运行；分为闹钟规则和条件规则；一个组可有多条，新组默认没有自动规则。 | 不是同步组本身；不是手动同步；不是跨组规则 |
| 闹钟规则 / Alarm Rule          | **定时同步**：按“哪周哪几天的哪时哪分”的日历规则触发，带时区；一个组可有多条。                 | 不是固定间隔轮询；不是条件规则 |
| 条件规则 / Condition Rule      | **计划同步**：由条件源触发，可组合：目录变动、目标应用启动/退出（后两者仅 Windows）；一个组可有多条。 | 不是 cron；不是闹钟规则 |
| 防抖窗口 / Debounce            | 条件规则命中后等待静默期（默认 30s，按组配置），期间新事件重置计时；同一组多个规则重叠触发时合并为最多一次后续同步。 | 不是限流；不是丢弃事件 |
| 立即同步 / Manual Sync         | 用户手动触发、绕过防抖的同步运行；受全局并发上限约束。                                         | 不是“强制覆盖”             |
| 同步运行 / Sync Run            | 一次触发产生的同步会话，作用域是“某同步组”；一组一根、组内单飞，组间可并行但受全局并发上限约束。 | 不是同步组，不是节点级任务，不是跨组共享运行 |
| 扫描 / Scan                    | 遍历同步根生成本地 Manifest；扫描期间的变动由 watcher 记录并在应用后复扫。                     | 不是校验                   |
| 变更通知 / NOTIFY              | 变更方发给同组内在线且与本机互相信任的节点的帧，携带 `runId`、`groupId`、变更摘要与向量快照。 | 不是传输本身；不持久化     |
| 变更序号 / Change Sequence     | `item_change` 上按组单调递增的本地变更编号，用于增量清单；每个 `(组, 路径)` 只保留最新序号。     | 不是版本向量；不是墙钟时间 |
| 拉取游标 / Pull Cursor         | 本机在某个组内已成功应用的对端变更序号；`MANIFEST_REQUEST` 从这里开始增量拉取。                  | 不是信任状态；不是推送进度 |
| 推送游标 / Push Cursor         | 本机在某个组内已通知给某个对端的本地变更序号；用于决定是否发送 NOTIFY。                          | 不是对端已应用；不是拉取游标 |
| 只收模式 / RECEIVE_ONLY        | 收到 NOTIFY 后，对**该组**临时生效的方向模式：只从发起方拉取。                                 | 不是永久配置               |
| 反推 / Reverse Push            | 只收模式结束后，若本地向量领先于源，立即把未推送变更推回源。                                   | 不是第二轮同步             |
| 传输会话 / Transfer Session    | 节点间一条连接内的分块、可续传的内容传输。                                                     | 不是持久连接               |
| 应用 / Apply                   | 把对端版本写入本地文件系统，含原子替换、PathCodec 编码与冲突副本生成。                         | 不是“提交”                 |
| 运行历史 / Run History         | 每次 Sync Run 的状态、统计与错误码记录，保留最近 200 次。                                      | 不是日志文件               |
| 诊断包 / Diagnostics Bundle    | 一键导出的 zip：脱敏配置、日志、清单摘要、冲突列表、平台能力信息。                             | 不含口令、私钥、文件内容   |

## 平台与生命周期

| 术语 (中文 / English)          | 定义                                                                             | 明确不是什么   |
|--------------------------------|----------------------------------------------------------------------------------|----------------|
| 自启动 / Autostart             | 设备开机后自动拉起节点。Windows 走 `HKCU\...\Run`；Android 走 `BOOT_COMPLETED`。 | 不是“默认启动” |
| 默认启动 / Start by Default    | 安装或首次运行后默认处于运行状态（托盘 / 前台服务）。                            | 不是开机自启   |
| 前台服务 / Foreground Service  | Android 上带常驻通知的长生命周期服务，类型 `dataSync`，是唯一合规的保活手段。    | 不是后台线程   |
| 保活 / Keep-alive              | 尽力让节点在后台存活；失败后靠闹钟 / WorkManager 恢复。**不承诺 100%**。         | 不是永恒后台   |
| 托盘 / Tray                    | Windows 端的常驻 UI 入口（最小化后不占任务栏）。                                 | 不是主窗口     |
| 平台能力 / Platform Capability | 某平台是否支持某功能（如监听第三方应用启停仅 Windows）。UI 必须按能力矩阵渲染。  | 不是运行时探测 |
| 错误码 / Error Code            | 共享层统一定义的稳定枚举（如 `BLOB_HASH_MISMATCH`），日志、UI 与文档共用。       | 不是异常堆栈   |
