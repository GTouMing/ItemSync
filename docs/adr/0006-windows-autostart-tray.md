# 0006. Windows 托盘应用 + 用户级注册表自启

- 状态：已接受
- 日期：2026-11-01

## 背景

需求要求“电脑开机自启动和默认启动”。“默认启动”指安装后即处于运行状态（托盘常驻），无需用户每次手动开启。

## 决策

1. Windows 端是**单进程托盘应用**，GUI 用 JavaFX；关闭主窗口默认最小化到托盘，托盘菜单提供“立即同步 / 打开窗口 / 暂停 / 退出”。
2. **自启动**：写入 `HKCU\Software\Microsoft\Windows\CurrentVersion\Run`，值为 `<安装路径>\ItemSync.exe --minimized`。用户级，不需要管理员权限。
3. **默认启动**：安装程序完成后直接启动一次；首次运行向导询问“是否开机自启”“是否启动后最小化”，选择持久化到配置。
4. 退出语义区分：`最小化到托盘`（节点继续运行）与 `完全退出`（停止同步，托盘图标消失）。
5. 不请求管理员权限；访问受保护目录时由用户显式授权或改用可写目录。

## 后果

- 自启只对当前 Windows 用户生效，多用户机器需各自配置。
- 进程被系统或用户杀死后无自动重启；如需看护，后续可加计划任务（另一条 ADR）。
- 无法同步需要提权的目录（如 `C:\Program Files`、系统目录），必须在 UI 中给出可读的失败原因，而不是静默跳过。
- 打包需自带精简 JRE（jlink），否则依赖用户机器上的 Java。

## 备选方案

- **Windows 服务**：开机未登录也能跑，但 Session 0 与桌面隔离，托盘/IPC 复杂度陡增。
- **任务计划程序**：可延迟启动、可提权、失败重试，但需安装脚本写任务，且用户不易审计。
- **服务 + 托盘双进程**：最健壮也最重，第一期不做。
