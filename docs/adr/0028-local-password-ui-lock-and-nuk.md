# 0028. 本机密码只锁 GUI，NUK 静默解锁节点身份

- 状态：已接受
- 日期：2026-11-02
- 替代：[ADR-0001](0001-local-account-and-pairing.md) 的本机账号、[ADR-0025](0025-single-local-account.md)；修订 [ADR-0013](0013-node-key-auto-unlock.md) 的 UI 解锁部分。

## 背景

ADR-0001/0013/0025 把“用户输入的口令”同时用于 UI 解锁和身份密钥库解锁。这样桌面端每次启动都要输入密钥库口令，开机自启必然弹窗，与“后台继续同步”的要求冲突。

需求方澄清：本机密码只锁 GUI 信息；没有密码不能查看同步根等信息；不影响开机自启、后台运行与已有同步；卸载即重置。

## 决策

1. 每台设备只有一个**本机密码**，没有用户名；首次启动设置，存 Argon2id 哈希。
2. 本机密码只锁 GUI：查看同步根、组 ID、邻居、在线状态、冲突、版本历史，以及改组/改信任、冲突裁决、版本恢复等 GUI 操作。后台同步、托盘“立即同步/退出”不需要密码；“打开”主窗口需要。
3. 应用启动时锁定；窗口从托盘重新显示时再次锁定；暂不做空闲自动锁，窗口可见期间保持解锁。
4. 首次启动生成 32 字节**节点解锁密钥（NUK）**，由平台密钥库封装（Windows DPAPI CurrentUser / Android Keystore）。NUK 静默解锁本机身份（TLS 私钥/证书），用户不输入、看不到；删除“启动时输入密钥库口令”的交互。CLI 与服务进程同样不要求本机密码，通过 NUK 解锁身份。
5. 修改本机密码不改变 NUK，不影响已有同步；忘记本机密码后后台继续运行，但 GUI 无法解锁。没有找回：Android 卸载清数据；Windows 卸载/清除数据目录重置；重置会丢失身份与信任关系，需要重新配对。同步根里的用户文件不删除。
6. 本机密码不加密配置、数据库或 Blob；静态安全仍依赖系统全盘加密（ADR-0018）。通知只显示“正在同步/已同步”，不显示路径、组 ID 或邻居。
7. 升级迁移：已有安装首次运行新版时，先设置本机密码并生成 NUK；如果身份仍由旧密钥库口令保护，只在迁移时输入一次旧口令，之后改由 NUK 解锁，不重新配对。

## 后果

- 这是 GUI 访问锁，不是静态加密：拿到已解锁系统会话或直接读数据目录的人仍能看到配置和内容。威胁模型必须在隐私说明中写明。
- DPAPI 绑定 Windows 用户；拷数据目录到另一台机器无法解密 NUK，需要重新初始化身份。
- NUK 失效（系统密钥库被清除、备份恢复、重装）时只能重新生成身份并重新配对。
- jpackage app-image 没有卸载器；Windows 需要额外提供“清除本机数据”动作或安装器卸载清理，且不得删除同步根。

## 备选方案

- **保留密钥库口令**：身份解锁依赖用户输入，开机自启必然弹窗，否决。
- **用本机密码派生 NUK**：后台同步需要本机密码，违反“不影响已有同步”，否决。
- **用本机密码加密全部数据**：后台无法解密，且与 ADR-0018 的明文存储冲突，否决。
- **空闲自动锁**：更安全但增加使用摩擦；第一期不做，可后续叠加。
