# 0018. 静态加密依赖系统全盘加密

- 状态：已接受
- 日期：2026-11-01
- 修订：本机密码只锁 GUI，不作为静态加密密钥，见 [ADR-0028](0028-local-password-ui-lock-and-nuk.md)。

## 背景

磁盘上的内容是否需要应用自己加密。Android 10+ 默认文件级加密（FBE），Windows 上 BitLocker 在专业版可用但并非默认。

## 决策

1. 同步内容（Blob、数据库、暂存区）**以明文存储**，安全性依赖操作系统全盘加密：Windows 用 BitLocker（安装向导中检测并提示），Android 依赖系统 FBE。
2. 应用自身只加密三类东西：
   - 口令：Argon2id（随机盐 + 内存硬参数）。
   - 私钥与节点解锁密钥：平台密钥库（DPAPI / Android Keystore）。
   - 传输：TLS 1.3（见 ADR-0011）。
3. 安装/首次运行向导检测 BitLocker 状态，未启用时给出一次性提示，不阻断使用。

## 后果

- 拿到未加密磁盘镜像的攻击者可以直接读取文件内容与元数据（含文件名清单）。这一限制必须在隐私说明里写明。
- Blob 哈希校验、跨文件去重、内容寻址全部保持简单，不需要“先解密再算哈希”。
- 若未来要加应用级加密，需新 ADR，并处理“加密后无法直接校验哈希”的问题（需保存明文哈希）。

## 备选方案

- **Blob + 数据库全加密**：安全最强，但性能下降、Android 需引入 SQLCipher 原生库、跨节点去重语义变化。
- **只加密数据库**：折中，但版本文件仍明文可读，给人虚假安全感。
- **可选加密开关**：两条存储路径，测试成本翻倍。
