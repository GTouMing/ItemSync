// TL;DR

核心同步任务可用，但界面是默认 Modena 控件直接堆叠：没有主次层级、没有进行中状态， 状态区把原始枚举和 JSON 直接展示给用户。更严重的是表单控件没有可访问名称， 冲突对话框把破坏性操作设为回车默认项，固定宽度的弹窗在 Windows 高缩放下会超出可用区域。

先修可访问名称与破坏性默认按钮，再处理缩放和状态表达。顺序：/design a11y → interaction → responsive → relayout。

// WHAT'S WORKING

诚实的破坏性文案

删除组、更换同步根、清除本机数据都写明后果与不可逆性；清除数据要求输入“清除”。

空状态有下一步

未配置同步组时直接提示点击“添加同步组”，不是只显示一块空白区域。

重活不占 UI 线程

同步、版本历史、设备列表都在 worker 中执行，再回到 FX 线程更新控件。
