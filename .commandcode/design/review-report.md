# ItemSync — Design Review

- **日期**: 2026-11-04
- **模式**: `/design review`（只评审，不修改）
- **审查面**: Windows JavaFX 桌面端，redesign 之后的主窗口与全部对话框
- **范围外**: Android 端（未参与本次 redesign，未做真机验证）、CLI
- **证据基础**: 源码、JavaFX 样式表、构建产物与自动化测试。未启动 GUI，未截图；首屏观感、字体回退、焦点环外观与高 DPI 实际渲染属于未验证项。

---

## TL;DR

redesign 已经建立了自己的世界：暖纸表面、墨色主操作、铜色选择与焦点、横向同步组标签、两列工作台和一个真正成为焦点的状态带。它不再是默认 Modena 加一排按钮，也不再像通用 SaaS 仪表盘。

主要问题不在方向，而在边缘状态：同步没有取消入口，动态错误不会被读屏主动播报，窗口初始尺寸在高缩放的小屏上偏大，同名同步组在标签栏里无法区分。这些是“能用但会让人卡住”的问题，不是视觉失败。

**结论：需要改动（Needs changes）。没有 HIGH，先处理 6 个 MEDIUM。**

## 第一印象

从实现的构图判断，首屏是：顶部一条浅色应用栏，品牌在左，“全部同步 / 立即同步”在右；其下是横向同步组标签；中央左侧一张带铜色左边线的状态带，右侧一列工具行。颜色记忆点是暖纸与铜色，不是常见的蓝紫 CTA 或深色终端。

这个方向避开了“AI 生成”的常见反射：没有居中 hero、没有三张同构卡片、没有渐变按钮、没有玻璃拟态。风险不在“太模板”，而在“太密”：小字号和状态信息量需要真实渲染确认。

由于未启动 GUI，以上是构图与样式证据，不是像素观察。

## 主流程走查（代码路径）

1. 首次启动 → 设置本机密码 → 设置同步根/组 ID/端口：表单已有可见标签与 `labelFor`，弹窗内容可滚动。
2. 主窗口 → 选择一个同步组标签：选中态是铜色下划线加粗，不使用颜色单独表达。
3. 点击“立即同步”：按钮变为“同步中…”，出现 14px 进度指示，相关操作被禁用。
4. 运行结束：状态带显示中文状态与时间，状态点变为完成/失败/空闲；冲突数进入徽标。
5. 进入冲突/版本/设备/规则：对话框共用主题，列表使用暖色选中态。
6. 空组、停用组、未加载组、同步失败、信任警告：均有文字说明，但部分禁用操作仍不解释原因。
7. 窄窗口/高缩放：主内容可滚动，弹窗内容可滚动且有高度上限；窗口初始尺寸仍需按屏幕收敛。

## 优先处方

1. **动态状态不可播报**：用 `/design a11y`。错误出现时移动焦点，或对状态区发可访问通知；不要只改文本。
2. **同步无法取消**：用 `/design interaction`。先确认后端是否有取消能力；没有就补接口，再上按钮。
3. **首启窗口偏大**：用 `/design responsive`。按屏幕可视区域收敛初始尺寸，保留最小尺寸与滚动。
4. **同名组难区分**：用 `/design interaction` 或 `/design writing`。同名时显示组 ID，或始终显示紧凑 ID。
5. **禁用无原因**：用 `/design interaction`。给受限操作就地原因，优先复用状态带已有的解释。
6. **10px 中文微标签**：用 `/design typeset`。中文微标签升到 11px，必要时减少同级信息。

## 做得好的地方

- **方向不是换色**：顶部组标签、两列工作台、状态带与侧栏改变了空间前提；旧版左栏加平铺按钮的构图已经不存在。
- **状态成为主角**：28px 组名、信号点、冲突徽标和人类可读运行状态，让“当前组发生了什么”先于工具按钮被看到。
- **危险动作有摩擦**：“接受远端”不再是回车默认项，使用错误色并二次确认；确认按钮写具体动词。
- **主题覆盖到对话框**：所有 Dialog/Alert 共用同一份样式表，内容型弹窗可滚动，尺寸按屏幕封顶。
- **颜色不单独承担语义**：状态点、徽标和错误都有文字伴随；铜色只用于选择、焦点和进行中。
- **表单不再是占位符冒充标签**：首次设置、解锁、添加组、组设置和闹钟规则都有可见标签与 `labelFor`。

## 结论

**Needs changes**：没有 HIGH 级阻塞，但 6 个 MEDIUM 会影响真实使用，尤其是同步取消、动态状态播报、首启窗口尺寸和同名组区分。

建议顺序：`/design a11y` → `/design interaction` → `/design responsive` → `/design typeset` → `/design finish`。
